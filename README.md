# Visit Greece

A responsive travel landing page built with **HTML** and **CSS**, showcasing top attractions in Greece and featuring a local tour guide profile card.

## Preview

The page opens with a full-width hero banner introducing Greece, followed by a three-column activity section highlighting the Acropolis, Elafonissi Beach, and Plaka. It closes with a tour guide profile card presenting a short bio.

## Features

- Full-width hero section with background image and text shadow for readability
- Responsive three-column activity layout using Flexbox
- Circular activity images with consistent sizing
- Horizontal tour guide profile card (image beside bio text)
- Custom Google Fonts (`Roboto Mono`) for a clean, modern look

## Tech Stack

- HTML5
- CSS3 (Flexbox, background images, object-fit, Google Fonts)
